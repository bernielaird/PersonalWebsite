How it works

  1. Scrape. A Java scraper collects every VCT match since 2023 (franchising era) from vlr.gg, including each map's 2D replay data (1,890 matches, ~4 GB).
  2. Clean. The pages become a validated SQLite database: rounds, buys, ~600k kills, plants and defuses, 3.7M player positions.
  3. Model. A calibrated LightGBM model predicts the round winner from players alive, time, spike state and economy. Trained on 2023–2025, tested on all of 2026.
  4. Credit. Each kill's change in win probability goes to the killer and victim. Deaths that are traded within 5 seconds cost half as much.
  5. Validate. WPA tracks vlr.gg's rating closely (0.90) but doesn't predict future maps better, so it's a description of what happened, not a better skill rating.
